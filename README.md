# Pet Shark public downloads

The files people download from [PetShark.ca](https://petshark.ca): finished game builds and other large files from
Pet Shark Productions Inc. They live here so they do not fill the website's own repository.

There is no source code here. Each download is a file attached to one of this repository's
[releases](../../releases); the repository itself holds only this page, one page per product and a list for the website
to read.

## How this repository is laid out

| Where | What |
|---|---|
| `README.md` | this page; the table above is rewritten each time something is published |
| `downloads.json` | the same list for programs: each product's current version, file, size, SHA-256 checksum and link |
| `<product>/README.md` | one page per product: what it is, how to run it, what is new |
| Releases | the files themselves, one release per product version, tagged `<product>-v<version>` |

Do not use GitHub's "latest release" link: it is one for the whole repository, so it points at whichever product was
published last. Link to a product's own file (the table above or `downloads.json`).

## Publishing

The table above, `downloads.json` and each product's page are rewritten whenever a file is published. Nothing here is
edited by hand except this text.
